Import a visual

A plug-in is a manifest — type, label, icon and fields (category, values) — and one JavaScript file that calls bi.registerVisual({ render(root, data, api) }).

Runs sandboxed. Imported code runs in an isolated frame with no network access. It can't read this page, cookies or sign-in tokens. It receives only its own visual's data, and can only ask to select data points or open See records.

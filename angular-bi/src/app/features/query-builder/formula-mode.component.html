Filter-context modification (CALCULATE-equivalent)

Real DAX's hard part isn't the arithmetic above — it's changing the filter context a measure is evaluated under, e.g. CALCULATE([Productivity %], Year = 2026). Per the feasibility tracker, that needs a real relationship/semantic layer (Cube.dev or equivalent) sitting on the data platform, not something this local demo approximates. Shown here as a labeled roadmap item, not faked.

CALCULATE(
  [Productivity %],
  Year = 2026
)
